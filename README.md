# ESC-Exploratory-Data-Analysis

> This project was created as a fun, hands-on playground to practice data analysis and predictive modeling using historical data from the Eurovision Song Contest (ESC).

---

## About the Project

The Eurovision Song Contest is notorious for its glitz, drama, and beautifully unpredictable outcomes. For anyone looking to sharpen their data science skills, it offers an excellent foundation of clean, accessible, and structured historical datasets. 

The main goal of this repository is **learning and experimentation**. While the ESC provides a great basis for building predictive models, we all know that the true winner is rarely chosen by numbers alone. External factors (such as geopolitical alliances, cultural trends, and politics) play a massive role. 

Therefore, this project doesn't aim for flawless predictions. Instead, it serves as a sandbox to explore objective features, test analytical methodologies, and discover a few fascinating insights along the way.

---

## Key Areas of Exploration

While playing around with the data, this analysis focuses on questions like:

* **Feature Importance of Obvious Metrics** 
* **The Role of Genre** 
* **Predicting Eurovision 2027** 

---

## Tech Stack

* **Language:** Python
* **Libraries:** pandas, numpy (Data Wrangling) | matplotlib, seaborn (Data Visualization) | scikit-learn (Predictive Modeling)
